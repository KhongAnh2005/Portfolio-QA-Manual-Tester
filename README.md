## 3. QA Knowledge

- **7 Nguyên tắc kiểm thử phần mềm (7 Fundamental Testing Principles):**
  - Kiểm thử chứng minh sự hiện diện của lỗi (Testing shows presence of defects).
  - Kiểm thử kiệt quệ là bất khả thi (Exhaustive testing is impossible).
  - Kiểm thử càng sớm càng tốt (Early testing / Shift-Left).
  - Sự tập trung của lỗi (Defect clustering).
  - Nghịch lý thuốc trừ sâu (Pesticide paradox).
  - Kiểm thử phụ thuộc vào ngữ cảnh (Testing is context dependent).
  - Ảo tưởng về sự vắng bóng của lỗi (Absence-of-errors fallacy).

- **Quy trình & Mô hình phát triển (SDLC / STLC):**
  - **Chu trình STLC:** Requirement Analysis, Test Planning, Test Case Design, Environment Setup, Test Execution & Bug Reporting, Test Closure.
  - **Mô hình phát triển:** Agile/Scrum (Sprint Planning, Daily Scrum, Sprint Review, Definition of Done - DoD, BDD Acceptance Criteria), V-Model, Waterfall, CI/CD Pipeline Integration.
  - **Môi trường kiểm thử:** Quản lý và phân tách môi trường Development, Test/QA, Staging và Production nhằm hạn chế lỗi sai lệch (false positives).

- **Cấp độ kiểm thử (Testing Levels):**
  - **Unit Testing:** Kiểm thử mức đơn vị mã nguồn.
  - **Integration Testing:** Kiểm thử tích hợp giữa các module, kiểm thử luồng dữ liệu qua giao diện, REST API và Database.
  - **System Testing:** Kiểm thử toàn diện chức năng và phi chức năng trên môi trường hoàn chỉnh.
  - **Acceptance Testing:** Kiểm thử nghiệm thu (UAT) xác nhận giá trị nghiệp vụ với Product Owner và Stakeholders.

- **Các loại kiểm thử (Testing Types):**
  - **Functional Testing:** Kiểm thử chức năng (Happy Path, Negative Path, Boundary & Edge Cases).
  - **Non-Functional Testing:** Kiểm thử phi chức năng gồm Usability Testing (Think-Aloud Protocol), Accessibility Audit (tiêu chuẩn WCAG trên MS Edge DevTools), Performance Testing cơ bản và Bảo mật phiên làm việc.
  - **Chiến lược thực thi:** Smoke Testing (Build Verification Testing - BVT), Regression Testing (bảo vệ chức năng cũ trước Code-Freeze), Session-Based Exploratory Testing (SBTM Charters & Heuristics), Cross-Browser & Mobile Emulation (BrowserStack).

- **Bộ tài liệu kiểm thử chuẩn mực (QA Deliverables & Documentation):**
  - **QA SOP & QA Strategy:** Quy trình thao tác chuẩn và chiến lược kiểm thử cho tính năng mới.
  - **Test Plan Document:** Kế hoạch kiểm thử tổng thể (Test Plan).
  - **Test Coverage Document & RTM:** Báo cáo độ bao phủ kiểm thử và Ma trận truy xuất nguồn gốc hai chiều (Requirement Traceability Matrix).
  - **Test Scenarios & Test Cases:** Kịch bản kiểm thử BDD (Given-When-Then) và Ca kiểm thử chi tiết theo định dạng chuẩn công nghiệp.
  - **Defect Ticket & RCA Report:** Báo cáo lỗi kỹ thuật và Tài liệu phân tích nguyên nhân gốc rễ (Root Cause Analysis qua phương pháp 5-Whys).
  - **Test Summary Report:** Báo cáo tổng kết kiểm thử phân tích rủi ro và đưa ra quyết định Go/No-Go Release Sign-Off.

- **Quản lý khiếm khuyết & Đo lường chất lượng (Defect Life Cycle & Metrics):**
  - **Vòng đời lỗi (Defect Life Cycle):** Luồng trạng thái chuẩn (New, Open, In Progress, Resolved, Retest, Closed, Reopened, Rejected).
  - **Defect Prioritization & Triage:** Phân định rủi ro kỹ thuật (Severity) vs. Mức độ ưu tiên kinh doanh (Priority), quản lý và tinh gọn Backlog trên Jira Cloud & Azure DevOps.
  - **Chỉ số chất lượng (QA Metrics):** Test Pass Rate, Requirement Coverage, Defect Density, MTTR (Mean Time To Resolution), Reopen Rate, trực quan hóa Dashboard qua Microsoft Excel PivotCharts.

- **Kiểm thử kỹ thuật & AI (Technical QA & AI-Assisted Testing):**
  - **Web Layers Mapping:** Phân tích luồng dữ liệu qua 3 tầng (Presentation Layer, Business Logic Layer, Data Layer).
  - **API Testing:** Kiểm thử tích hợp RESTful API với Postman (HTTP Methods, Status Codes, Headers, JSON Schema & Payload validation).
  - **Database Testing:** Truy vấn SQL (`SELECT`, `JOIN`, `WHERE`) kiểm tra tính toàn vẹn dữ liệu dưới Backend.
  - **AI in QA:** Prompt Engineering với AI Agent hỗ trợ sinh kịch bản kiểm thử BDD theo khung CICF, tạo dữ liệu giả lập quy mô lớn (Synthetic CSV Datasets) và dự đoán vùng rủi ro mã nguồn (Defect Hotspots).
